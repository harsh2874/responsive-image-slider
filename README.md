# Vanilla JS Image Slider

A simple image slider built using **HTML, CSS, and JavaScript**.

## 🔗 Live Demo

You can view the project live here:  
[Click to View](https://harsh2874.github.io/responsive-image-slider/)

## 📌 Overview

This project demonstrates how to create a responsive image slider using **vanilla JavaScript**.  
It allows users to navigate through images with next/previous buttons.

## ✨ Features

- Next/Previous navigation buttons
- Responsive design for different screen sizes
- Smooth transitions between images

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/vanilla-js-image-slider.git

   ```

2. Navigate to the project folder.

3. Open index.html in your browser.

📂 Project Structure

└── images/
